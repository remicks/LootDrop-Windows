# LootDrop version 2 — Help

## Start here

1. Open Discover Games and choose Refresh.
2. Search or select platforms/stores to narrow the offers.
3. Hover over a card's small icons for explanations, or click Details for the full offer.
4. Choose Open website, review the destination preview, then confirm only if the address looks right. Check the final price on the store.
LootDrop finds offers and tracks your choices. It never signs in or claims games for you.

## Status icons: address, price and time

Address icon ↗: the HTTPS address is supported. This does NOT prove the page works, the destination is trustworthy, or the game is free. ⊘ means the address is blocked/unavailable; … means checks are pending.
Price icon ✓: a supported store catalog supplied free-price evidence. ? means price unverified; ! means unavailable/expired/flagged. It is never a checkout guarantee.
Time icon ◷: cached or saved-only information; refresh is required. ! means the listed expiration has passed.
Hover for explanations, or click any status icon to open offer details. Icons have accessible text labels and can be reached using Tab.

## Why is Open website disabled?

Cached and saved-only offers must return in a fresh live feed before they can open. Expired offers, unsupported addresses, your not-free flags and rejected store checks also disable opening.
Click Details to see the reason. Refresh if needed; do not treat an old cached listing as a current promotion. A live but unverified price still requires your own checkout check.

## Offer details, regions and price checks

Details shows the provider, platform, actual destination domain and full supported URL, expiration, last provider refresh, last address-format check and last available price check. The full description and your local flags are here too.
Supported Steam/Epic price checks use the US catalog. Regional/account eligibility may differ. No recorded price-check time means there is no recorded catalog response for this listing. A cached Epic catalog can retain its original check time.
Address checks are local format checks, not downloads of arbitrary claim pages.

## Wishlist, claimed games and not-free reports

♡ / ♥ adds or removes an offer from your Wishlist. □ / ✓ manually marks it claimed or undoes that mark; LootDrop cannot see your store account. Each button's hover text describes its current action.
Use No longer free inside Details to hide a bad offer from Discovery on this PC. You can undo the flag there. This is a local flag, not a report sent to a provider.
Opening a website never marks an offer claimed automatically.

## Feeds, offline cache and source health

Hover over the Feeds button for each provider's status and last success. Click it for a pinned explanation. A warning indicates a source problem or unreadable cache.
If a source fails, its last successful results may remain visible with a Cached label and disabled opening. Healthy sources continue updating. A successful empty response retires that source's cached offers. Refresh normally runs every 20 minutes while the app is running.

## Duplicate groups and separate store routes

Matching full titles are grouped so related offers stay together. Expand/collapse the group to view the separate cards. Every card keeps its own provider, destination, expiration and personal flags.
Edition and DLC names are not stripped. Grouping is a convenience, not proof of identical products. Marking one route claimed does not mark another route claimed. If an older record cannot be matched confidently, it stays separate.

## Search, filters and estimated value

Type in the search box to match titles, descriptions or platforms. Platform buttons can be combined. A normal store click selects one store; hold Ctrl to select several. All clears that filter category. Sort by newest, advertised value, expiration or title.
Hover over All Platforms for live counts. Savings/value figures use providers' advertised retail prices and are estimates—not money paid, verified savings or account ownership.

## Backups, export, import and recovery

Settings contains Export library, Import / review and Restore backup. Before the first library change each UTC day, a snapshot is saved; the 20 newest managed snapshots are kept.
Import/restore shows a preview before replacing saved offers and named themes. Cancel leaves the collection unchanged. Existing bytes are backed up first. Imported wallpaper paths and device/startup preferences are not applied.
Exports contain collection information and links. They are not encrypted; share deliberately. A damaged backup can stop saving rather than silently replacing your only recovery copy.

## Themes, wallpaper and performance

Themes offers 18 presets, including dark, light, pastel and neon combinations. Select a preset, adjust HEX/RGB if desired, and save a named custom theme. Its base colors are retained when reloaded.
Wallpaper is optional and copied to the managed local folder. Low graphics mode disables covers/wallpaper. Software rendering is available for driver problems and takes effect after restart. Large or unsupported images are rejected for safety.

## Tray, startup and keyboard access

Settings controls minimize/close-to-tray behavior. Use the tray menu's Exit to fully quit. Start with Windows is opt-in and uses this Windows user's startup entry; enabling it does not require administrator access.
F1 opens Help. Tab and Shift+Tab move between controls; Enter/Space activate buttons. Escape closes offer details. Use the visible Details button if hover is inconvenient. Compact sidebar buttons retain hover names.

## Store sign-in shortcuts and remembered sessions

LootDrop never collects, stores or transmits your store passwords, cookies or sign-in tokens. Sign-in happens in your default browser, which sends your credentials securely over the internet to the store or its chosen identity provider. Remembered sessions and saved passwords are managed by your browser/store, not LootDrop; browser sync may copy them to your browser account if enabled.
Use the same browser profile when opening offers. Choose the store's Remember me option on a trusted personal computer. Private browsing, session expiry and security checks can require another login. LootDrop cannot detect whether you are signed in, bypass two-factor authentication or claim games automatically. Check the final address before entering credentials. To sign out, use the store website; manage saved passwords and sync in your browser settings.

## Checking and downloading app updates

Open Settings and find App updates. Choose Check for updates. Nothing is checked automatically. Enable Include tester prereleases only if you want test builds; the setting starts off each session.
If a newer supported release exists, read its notes, select the installer or portable ZIP, then choose Download unsigned package and a local folder. Existing files are not overwritten; use another folder if necessary. Cancel stops the transfer.
The package is saved only after its size and SHA256 match GitHub metadata. A checksum is not a publisher signature or a safety certification. Nothing is launched or installed automatically. Back up your library and close LootDrop before manually updating. Keep antivirus/SmartScreen enabled.
GitHub receives your network address for checks/downloads; no store credentials or collection data are sent. A GitHub error is shown as a failed check, not a claim that you are up-to-date. Only supported numeric version tags among the 100 recent published releases are considered. The release page remains available if packages are missing or unsupported.

## App icons and themed desktop shortcuts

Themes > App icons contains Midnight Purple, Electric Blue, Neon Cyan, Emerald Green, Crimson Red, Sunset Orange, Hot Pink and Royal Gold. Choose one independently of the app theme, or keep Match app theme. Your choice is saved on this PC and is retained when you import a collection.
The window and system-tray icons follow this choice. Windows may retain a pinned shortcut's own icon; choosing a running-app icon does not rewrite existing pins or shortcuts.
In the installed or portable build, Create separate themed desktop shortcut makes a new color-named shortcut. Existing shortcuts are not overwritten. Moving a portable EXE can break a shortcut that points to its old location. Windows controls taskbar pinning; use the newly created shortcut to pin your chosen color.
All eight colors are also available through a shortcut's Properties > Change Icon: browse to LootDrop.exe and select a variant. You do not need loose .ico files. The executable's default Explorer icon stays Purple. No registry or startup change is made.

## Desktop sidebar mode: reserved screen space

Settings > Desktop sidebar mode pins LootDrop to the left or right edge and asks Windows to reserve that strip of your selected display. Other maximized apps use the remaining work area. Ordinary windows remain movable, and fullscreen games or Windows system screens can cover the sidebar. This is not a security boundary.
Choose Current display to capture the display LootDrop is on when docking starts, or choose a specific display. Width choices use logical pixels and may be reduced to leave room for other apps. If the display is unplugged, the primary display is used; if it is too small, docking turns off safely.
Use the page menu at the top for Discover, collections, Settings, Themes and Help. Platforms & stores expands the filters. The arrow button returns to the normal window; the dash hides to tray. Hiding, minimizing or exiting releases the reservation. Restoring from tray reserves space again if enabled. Docking remembers your preference on this PC; importing a collection cannot enable it.
No administrator access, new network requests or Windows security changes are needed. Explorer restarts and display/DPI changes trigger a fresh position negotiation. If negotiation fails, LootDrop releases its reservation and returns to a normal window.

## Privacy and safe testing

Collection data, cache, themes and backups stay under the version 2 LootDrop local-data folder. The iOS fork and beta have separate projects/data. There is no store login, password storage, cloud sync, automatic claim or diagnostic upload.
Public HTTPS sites can still be malicious or redirect elsewhere. Inspect the browser's final address and price. Do not disable antivirus or SmartScreen for an unsigned test build.
If something fails, note the provider message, app version and steps. Review any exported files before sharing them.
